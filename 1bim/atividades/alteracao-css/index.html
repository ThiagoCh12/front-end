Linguagens de Programação

C (1972)

Base para sistemas operacionais como Unix e Linux.

Python (1991)

Uma das linguagens mais populares do mundo, usada em IA e ciência de dados.

JavaScript (1995)

Criada em apenas 10 dias por Brendan Eich. Domina o desenvolvimento web.

Curiosidade

JavaScript não tem nenhuma relação com Java, apesar do nome.

Curiosidades Tech

Spam vem de um presunto

O termo "spam" para emails indesejados vem de um esquete do Monty Python onde a palavra SPAM era repetida sem parar.

Bluetooth tem nome viking

Nomeada em homenagem ao rei Harald "Bluetooth" Gormsson. A ideia era "unificar dispositivos".

O Google já quebrou a internet

Em 2009, o Google marcou acidentalmente todos os sites como maliciosos por 40 minutos.
